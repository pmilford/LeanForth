Branch `parallel-1`, range `c240a927..47402828`, re-checked as `47402828..7d612810`; it implements the

## Findings and their fixes

1. **The "input moved" guard was under-tested** (medium, blocking): seven reviewer faults in `check-run.fs`
   survived, and a move found at the last tick was not pinned as a fault. Closed: a table-driven test moves each of
   the ten parts of `ck-parts`; tests of `ck-final`, the tick's cut, `ck-pre-guarded`, `ck-faulted?` and
   `ck-stopped?`, the JSON "stopped" field and the snapshot not being written; nine re-planted faults caught.
2. **A start-up file reached the test hooks through `bin/leanforth`** (medium, blocking; also true of main):
   Gforth loads the file `GFORTH_ENV` names (or `~/.config/gforthrc0`) before `src/main.fs`, and a word defined
   there (`task-cores-test`, `lf-sched-fault-hooks`) switched a test hook on. Closed: `bin/leanforth` and
   `scripts/ndjson-reexport.sh` export `GFORTH_ENV=off`, with a test; in the re-check, the export moved above the
   `verify` branch, whose own Gforth run had still loaded the file. Other routes checked: no `.gforthrc` of the
   working directory is read; `~/.config/gforthrc` only when interactive; `GFORTHPATH` only finds the image; an
   `-e` passed through the wrapper is ignored; Gforth 0.7.3 reads no start-up file.
3. **Reuse** (medium): `ck-slab@` copied `tf-slab-data`. Closed: `slab-data` in `lib/slab.fs` replaces both, and
   `env-snapshot.fs` now requires `lib/slab.fs` itself (a word-for-word replacement in a kernel file).
4. Tables were compared by slot count: closed, by block address (`htab-base`) and count.
5. The cut: verdicts are read only below the slots final at the last clean comparison (sound: a slot final then
   was published before any later move). Freezing the shared tables during a run is not small (`htab` has no thaw;
   stores and slabs no freeze): plan 9.4.8p and ADR 0009.
6. `COMMAND_LINE.md` states the limit: a change undone between two comparisons is not seen.
7. The stress test runs 5 repeats in the tiers and 20 in the nightly run.
8. `parallel-init.py` requires the serial run to exit 0.

Style: a table of parts instead of words leaving 8 and 18 items; `cli-reason` split; `check-run.fs`'s globals
baseline 19 to 20 for the read-only `ck-parts` table (accepted).
