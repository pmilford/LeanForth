## Findings
### M1 (medium): `lf-whnf-stuck` answers "none" for a projection applied to arguments; Lean finds the metavariable
`src/front/whnf.fs:372-376` (`ws-app`): the default branch also catches a projection at the head; Lean's
`getStuckMVar?` (Meta/WHNF.lean:381) has `| .proj _ _ e => getStuckMVar? (← whnf e)`. With `?q : Prod (Nat → Nat)
Nat`: `?q 0 proj lf-whnf-stuck` gives `false unsupported` (fine); `?q 0 proj fk app lf-whnf-stuck` gives `false
outcome-ok` (none), on both Gforths; pinned Lean prints `stuck q` for both. Fix (exact port):
```forth
\ getStuckMVar? of a projection: its structure's whnf; a structure whose
\ head is a plain metavariable is stuck on it (whnf leaves it); any other
\ needs whnf.
: ws-proj ( proj -- mvar true outcome | false outcome )
  lf-proj-struct wc-margs wc-spine ok-then? 0= if false swap exit then
  dup wc-plain-mvar? if true outcome-ok else drop false outcome-unsupported then ;
\ ws-app:        lf-tag-projection of nip ws-proj endof
\ lf-whnf-stuck: lf-tag-projection of ws-proj endof
```
(minimum: `lf-tag-projection of 2drop false outcome-unsupported endof`). Tests: `T{ ?q 0 proj fk app lf-whnf-stuck ->
?q true outcome-ok }T`; `stuckCase (mkApp (mkProj ``Prod 0 q) k)` in check_whnf.py and its .lean file.

### M2 (medium): `ws-major-head` reads a non-constant head as a constant reference (unchecked memory read)
`src/front/whnf.fs:358` calls `wc-foldable?` (whnf.fs:201) on any major-premise head; via `wc-succ?` (200) to
`wc-name` (155): `lf-term-first@ lf-cref-slot lf-cref-name@`. For a free variable, lambda, pi, sort or literal the
first field is not a constant reference; `lf-cref-slot` and `store-slot` do no bounds check. whnf itself only calls
`wc-foldable?` on constants; getStuckMVar? is affected. Probes: `Nat.rec m z s (fun _ : T => #0)` with
`lf-whnf-stuck` THROWs -9 on Gforth 1.0.0 for some T (on 0.7.3 one case answers `false ok` silently); a free variable
whose number equals Nat.succ's reference index gives `false unsupported` for `Nat.rec m z s (f Nat.zero)` where Lean
gives none. Fix:
```forth
: wc-succ? ( head -- flag )
  dup wc-const? if wc-name lf-menv-nat-succ? wc-margs slab-count 1 = and
  else drop false then ;
```
Tests: `T{ nat 0 bv lam recm lf-whnf-stuck -> false outcome-ok }T`; the deterministic free-variable case on both hosts;
a planted fault removing the tag check.
