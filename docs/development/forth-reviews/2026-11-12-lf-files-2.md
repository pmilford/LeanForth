### N3, low: stale `lfc-failed?` / `lfc-refused?` across runs in one Forth session

Both flags are cleared only in `lfc-staging` (`check-lf.fs:167-169`). `cli-text-run` (`leanforth.fs:918`) calls `cli-text-report` even when `ck-snapshot-import` fails before `lfc-staging` runs.

Reproduced in a Gforth 1.0 session:
- a text stopping with error 51 (exit 2);
- then `/nonexistent/x.snap` with `cli-snapshot!` and `01-identity.lf`;
- result: the old error 51 is printed again, with exit 2. With the flag cleared by hand, it says "the snapshot was refused", exit 4.

It fails closed (no verdict). `bin/leanforth` is not affected: one command per process. Fix:

```forth
\ check-lf.fs (exported)
: lfc-fresh ( -- ) false lfc lfc-failed ! false lfc lfc-refused ! ;
\ leanforth.fs
: cli-text-run ( -- )
  lfc-fresh cli-text-loaded ok? if cli-text-lines ck-check then cli-text-report ;
```

Use `lfc-fresh` in `lfc-staging` too, and add a session test.

### N4, low: name-store capacity give-back untested

I planted `: lfc-rooms-back ( -- outcome ) ck-restore ;` (name capacity not given back). It survived `tests/cli/leanforth.fs` and `tests/author/author.fs`. The reason: `capacities?` (`tests/cli/leanforth.fs:211-213`) omits the name store. Fix: add `lf-name-capacity lf-name-default = and` to `capacities?`, and plant this fault.

### N5, low, potential (by reading the code): a THROW under `lfc-made` skips the give-back

The stage passes a producer's THROW on (`tests/core/stage.fs:312`). A THROW under `lfc-made` therefore skips `lfc-empty`, `lfc-rooms-back` and `lfc-sharing-back`. `ck-release` does not undo them, because `ck-unfeed` only acts after the feed began. Five capacities stay at `feed-most` and term sharing stays off for later runs in the session. `cli-restored` cannot see it. The stage itself is rolled back and freed, so no records survive. Suggested factoring:

```forth
: lfc-made? ( c-addr u -- outcome code )
  ['] lfc-made catch dup if nip nip outcome-invalid swap then ;
: lfc-text ( c-addr u -- outcome )
  lfc-sharing! lfc-rooms ok-then? if lfc-made? else nip 0 then >r
  lfc-empty lfc-rooms-back ck-first lfc-sharing-back r> throw ;
```
