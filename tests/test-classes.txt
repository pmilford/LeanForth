# The class of every test target of make check, and of every test program no target runs
# (owner, 2026-11-14: "split the tests"; docs/development/TESTING_STRATEGY.md, "Unit and
# end-to-end tests"). The one list of the classes: the Makefile reads it for make test-unit and
# make test-e2e, scripts/test-tier.py for the suites of each change tier, and
# scripts/test-classes.py (make check-test-classes, part of make test) fails when a leaf target
# of make check, or a test program under tests/, is in no class, or a row names nothing.
#
# Columns: a target of the Makefile (or a test program's path), its class, a note.
#   unit    a Forth test file that loads a module and runs its cases, or a Python test of a
#           script (and the checks that run no Forth). Runs on Gforth 1.0, instrumented (make
#           coverage-check), on gforth-fast (make test-unit GFORTH=.tools/gforth/bin/gforth-fast)
#           and, at the push and in the daily run, on Gforth 0.7.3; the tiers' engine runs take
#           those whose recipe runs Gforth.
#   e2e     runs bin/leanforth on an export, a snapshot or .lf files, compares with pinned Lean,
#           runs all of Init, or plants faults in a copy of the tree: once, on Gforth 1.0 (make
#           coverage-check for those of make test, make check-rest for the others).
#   manual  a test program no target of make check runs: benchmarks and measurements run by hand.

# A tactic's own targets, found by the Makefile from tests/front/tactics/NAME/ (tactic plug-in
# design, slice (a1)): a pattern row classes every one of them.
test-tactic-*-e2e                  e2e     tests/front/tactics/NAME/check.py: its .lf runs
test-tactic-*                      unit    tests/front/tactics/NAME/test.fs: its unit tests
